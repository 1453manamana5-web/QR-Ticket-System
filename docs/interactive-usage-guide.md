# 操作式の使い方ガイド

管理・受付それぞれの端末が登録・承認され、アプリを使用できるようになった時点で、自動的にガイドを開始します。承認待ちの端末がガイドを経由して本番画面へ入ることはできません。既存端末も、このバージョンのガイドをまだ開始していなければ初回に開始します。

管理アプリは「設定 → 使い方ガイドを始める」から再開できます。「最初から練習する」で最初へ戻ります。受付アプリは右下の「設定」から開始できます。開始した受付ガイドの間はカメラを外し、本番の読み取り処理を止めます。手動で開始した後は、実際の受付を再開するボタンを押してください。

## 練習する内容

管理ガイドでは、本番と同じApp・チケットデザイナー・分析グラフを、独立したメモリー内のバックエンドへ接続します。

- イベント作成、日付入力、公開、受付準備、オフライン受け渡しQRの作成・保存操作。
- 通常／予備の枚数指定、発行、予備の保存、印刷準備、キャンセル、再準備、印刷完了。
- 画像追加、QR・番号・文字、位置・回転・サイズ、複数設定パネル、レイヤー、保存、実寸、印刷操作。
- 一覧・検索・QR表示・無効化・有効化・状態変更・削除。
- 端末承認・接続確認・操作パネル・入口／出口切替・停止・更新。
- 会場内人数グラフ、分析の読み方、端末名、バックアップ保存・復元の入口、試験機能と診断。
- 受付開始、入場、重複エラー、退場、再入場、停止。
- 受付開始／終了処理／終了の状態変更、履歴削除、本番前の確認。

部員管理は本体で近日公開のため、操作対象外です。実際の音・カメラ・暗所での読み取り・AirPrint・端末間の通信・バックアップファイルの実復元など、実機や外部接続が必要な検証はガイドの完了と別です。ガイド内にその確認を案内します。

## 進行と保存

枠で示したボタンや入力欄を実際に操作すると次へ進めます。データ作成などの手順では、結果の画面が表示されたことも確認します。中断すると練習用データを破棄し、管理ガイドは保存された章の最初から再開します。章のやり直しでも練習データを初期化します。短い受付ガイドは再開時に最初から練習します。

進行状況だけを端末IDごとのlocalStorageへ保存します。サイトデータを消した場合や別ブラウザーでは新しく開始します。保存できない場合は画面に表示し、そのセッション中は練習を継続できます。

## 本番からの分離

練習中のイベント、在庫、端末、設定、デザイン、予備印刷の台帳はメモリー内で独立しています。本番のFirebase、localStorageの設定、IndexedDBの台帳に書き込みません。印刷やファイル保存・復元は練習メッセージに置き換えます。練習用のQRには無効な練習用認証トークンを用い、実際の受付へ渡さないでください。

ガイドを開いている間も、外側の本番アプリが通常行う購読・ハートビートなどは継続します。練習の操作を本番へ送信することはありません。

## 検証

各章の実際のコンポーネントを自動操作し、全操作対象と次の画面が存在すること、ライブサービスと永続ストレージへアクセスしないこと、承認後の自動開始・中断・再開・完了後の再開始、受付の重複判定と人数を検証します。実ブラウザーの視覚確認とiPad実機の確認は未実施です。
