# 予備チケットの準備とオフライン印刷

通常分500枚、予備分200枚の場合は、オンラインのうちに合計700枚を発行します。入場用・退場用の両方の受付端末へ、予備を含む700枚すべてを事前に読み込んでください。予備指定や印刷だけで、入場扱いになることはありません。

1. 印刷を担当する1台の端末で、管理画面のチケットデザインを開き「予備印刷」を選びます。
2. 開始501、終了700など、発行済み・有効・未使用の連続番号を指定して「この範囲を予備として端末に保存」を押します。欠番や使用済み番号を含む範囲は保存できません。
3. 「オフライン用の予備印刷画面を開く」を押し、「オフライン起動の準備完了」を確認します。その画面をブックマークし、通信を切って開き直せることを本番前に確認してください。
4. 当日は必要な枚数（初期値20枚、残数が少なければ残数）を指定して印刷します。ポップアップの許可が必要です。自動で印刷が始まらなければ、印刷画面の「印刷する」を押します。
5. 紙が正しく出たことを確認して、元の画面の「印刷完了して次へ」を押します。501〜520なら、次は521からになります。印刷ダイアログを閉じただけでは次の番号へ進みません。

中止時は、同じ番号の紙が手元にないことを確認して「印刷を中止・未印刷に戻す」を押します。同じ番号からやり直せます。「同じ分を再印刷」する前には、先に出た紙を回収してください。確認待ちの状態と完了記録は再読み込み後も保持されます。同じブラウザーの複数画面から同時に新しい印刷を確保する操作は拒否します。

## 保存先と運用上の制約

- 保存データと印刷記録は、その端末・そのブラウザーだけに存在します。同期されないため、予備印刷は1台で担当してください。別端末の通常印刷から予備が自動除外されるわけではありません。
- 準備した端末では予備番号を通常印刷から除外します。保存デザインは準備時点のものです。デザイン変更後は予備も保存し直してください。既存の印刷済み記録は保持し、確認待ちがある間は上書きできません。
- サイトデータの消去、ブラウザー変更、端末変更で準備済みデータを利用できなくなります。プライベートブラウズは避けてください。
- 専用の予備印刷画面はFirebase認証やオンライン照会を必要としません。通常の管理画面全体をオフライン対応にする機能ではありません。Firebaseへの新たな書き込みや有料サービスは追加しません。
- インターネットがなくても印刷できますが、プリンターとの接続は必要です。iPadとプリンターの実機で、事前に通信を切った状態の起動・印刷・読み取りを確認してください。

## 検証

自動テストで連番の検証、キャンセルと確定、再読み込み後の復元、同時操作、通常印刷からの除外、保存デザインと指定枚数での印刷生成、Firebase認証を通さない起動、Service Workerのキャッシュと通信失敗時の復元を確認します。今回の直接ブラウザー確認は利用上限により実行できていません。実機でのAirPrintと用紙品質は未確認です。
